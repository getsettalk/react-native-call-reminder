How a reminder call flows
You decide when to ring; the library rings, speaks and reports back — without ever losing an event.
1 · Trigger
Your server
A cron finds doses due now (user's timezone) and sends one call per user.
2 · Push
FCM / APNs
Android: high-priority data message, short TTL. iOS: time-sensitive alert + category.
3 · Ring
showIncomingCall()
Insistent alarm-category notification → full-screen call screen, or heads-up.
4 · Speak
User answers
Ringing stops; device TTS reads speakText in language (fallback voice + text).
5 · Report
Events → you
answered, action: taken, timeout… via listener, headless task or the durable queue.
No answer → timeout, even after process death
Full-screen denied → sticky heads-up
On a phone call → quiet notification
Same callId twice → suppressed
