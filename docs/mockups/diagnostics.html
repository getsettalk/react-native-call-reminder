"Why didn't my reminder ring?" — answered remotely
getDiagnostics() explains what is stopping reminders on a user's phone, so you can tell them exactly what to change.

Send it to your backend

const d = await CallReminder.getDiagnostics(); // e.g. a realme phone after the user swiped the app away { manufacturer: 'realme', rom: { name: 'realme UI', version: 'V5.0' }, forceStoppedRecently: true, exitReasons: [{ reason: 'user_requested', … }], permissions: { notifications: 'granted', fullScreenIntent: 'granted', batteryUsage: 'restricted', oemHasAutoStartManager: true, }, standbyBucket: 'rare', interruptionFilter: 'all', notificationChannels: [{ id: 'call_reminder_incoming', importance: 'high', blocked: false }], tts: { engine: 'com.google.android.tts', defaultLanguage: 'hi-IN' }, }
